# 六种叙事结构

## 选择规则（先看听众）

| 听众 | 他最关心 | 用哪个结构 |
| --- | --- | --- |
| 决策者（要批预算/拍方案） | 我要不要同意 | **SCQA → 方案 → 请求** |
| 同行/评审 | 你的逻辑站不站得住 | **金字塔（结论 + 三论据 + 证据）** |
| 客户 | 你能解决我什么问题 | **问题 → 代价 → 方案 → 证据** |
| 投资人 | 天花板与胜率 | **市场 → 痛点 → 方案 → 数据 → 团队** |
| 全员/宣讲 | 我们在往哪走 | **时间线（过去 → 现在 → 未来）** |
| 快速同步（5 分钟） | 结论与风险 | **PREP（观点-理由-例证-重申）** |

---

## 一、SCQA（默认首选）

```
S Situation 情境：听众都同意的现状（建立共识，1 页）
C Complication 冲突：出现了什么变化/落差（制造张力，1 页）
Q Question 问题：由此产生的那个关键问题（1 句话，可并入 C）
A Answer 答案：你的结论 + 三条论据 + 证据（主体，3–5 页）
```

**好用在哪**：先给共识再打破，听众会自己产生"那怎么办"的疑问，你的结论就成了答案而不是主张。

**失败表现**：S 太长（讲了三页背景）、C 太弱（"也面临一些挑战"）。

## 二、金字塔（结论先行）

```
结论（1 页）
├─ 论据 1（主张 + 证据）
├─ 论据 2（主张 + 证据）
└─ 论据 3（主张 + 证据）
所以 → 请求/下一步（1 页）
```

**检查 MECE**：三个论据互不重叠、合起来能覆盖结论。重叠的两个论据合成一个；覆盖不全的补一个。

**适合**：评审、答辩、上级汇报。**风险**：开场就给结论，若听众没有背景会觉得突兀——前面加 1 页 SC 垫一下即可。

## 三、问题树

```
核心问题
├─ 子问题 A（占比 X%）→ 解法
├─ 子问题 B（占比 Y%）→ 解法
└─ 子问题 C（占比 Z%）→ 不做（说明为什么）
```

**关键**：每个子问题带**占比/权重**，否则听众不知道先做哪个。最后一定要有一栏「不做」——不做决定也是决定。

## 四、对比式（选方案）

```
方案 A / B / C 横向对比（同一维度表）
→ 差异所在（2 条，不要 5 条）
→ 我建议 A，因为 {最关键的那一条}
→ 代价与补救
```

**规则**：对比表**维度 ≤5 个**，且每个方案都有明确的致命缺点（都完美的对比表没人信）。

## 五、时间线（进度/规划）

```
过去（已发生，带数字）
→ 现在（正在做，带风险）
→ 未来（三个节点，每个带可验收指标）
```

**失败表现**：全程"接下来我们会继续推进"。未来段必须写清**日期 + 交付物**。

## 六、PREP（5 分钟同步）

```
P 观点：一句话结论
R 理由：2–3 条，每条一句
E 例证：一条最硬的证据
P 重申：所以请求是 {X}
```

**最适合**：临时被叫去汇报、周会、跨部门同步。**4 页以内**。

## 结构模板：10 分钟决策汇报（可直接套）

```
P1 封面：{一句话结论}
P2 结论与请求：{要什么决定，今天就要}
P3 S+C：现状与落差（一张对比图）
P4-Q：关键问题（一句话 + 一个数据）
P5-P7 三条论据各一页（判断句标题 + 一个证据主体）
P8 方案与代价（对比表 + 我建议）
P9 风险与应对（表格）
P10 请求：要人/要钱/要决策 + 时间点
```

10 页 = 10 分钟，**每页 1 分钟**，这个换算比任何"演讲技巧"都实用。

## 标题句的三个模板

1. **因果型**：`因为 {原因}，所以 {结果}`
   → 「因为小客户从不使用核心功能，所以 6 个月内流失率是小客户的 2.4 倍」
2. **对比型**：`{A} 是 {X}，{B} 是 {Y}，差异在 {Z}`
   → 「竞品靠低价获客，我们靠交付速度，差异在实施周期 6 天 vs 21 天」
3. **行动型**：`要 {目标}，只需 {N} 件事`
   → 「要半年把续费做到 80%，只需做三件事：教会核心功能、拆小客户包、加交付人手」

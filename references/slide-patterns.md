# 12 种页型：每页放什么

## 通用规则

- 每页只有**一个主体**（一张图 / 一个表 / 一组数字 / 一个流程）。
- 标题是判断句；正文是**支撑这句话的**，不是解释这张图是什么。
- 页面上**字号不超过 3 种**、颜色不超过 3 种。
- 任何一页，如果截图发到群里别人看不懂，就该重做。

---

## 1. 结论页（P2，最重要）

- 内容：一句话结论 + 三条支撑（每条形如「因为 X」）+ 一句请求
- 常见错误：写成"汇报大纲"。**结论页不是目录，是答案。**

## 2. 现状 vs 目标页

- 一左一右两个数字，中间一个箭头，箭头旁写差距的量级
- 必须标口径与时间范围
- 例：`71% → 80%（续费率，季度末到期客户口径，全年目标）`

## 3. 趋势页

- 一张折线，最多 2 条线（本司 + 大盘/竞品）
- 标题写**趋势的结论**，不是"趋势图"
- 不要放 5 条线，谁也看不清

## 4. 结构分解页

- 堆叠柱或饼图，**最多 5 个分类**，其余合并为"其他"
- 每个分类标占比 + 一句"so what"

## 5. 漏斗页

- 横向漏斗，每层标转化率与绝对量
- 最窄那一层用高亮色，标题指出它就是问题所在

## 6. 对比页（选方案）

- 表格，维度 ≤5，方案 ≤3
- 每个方案至少写一条"代价"
- 表格下方一句话：我建议 X，因为 {最关键差异}

## 7. 矩阵页（定位/优先级）

- 2×2：横轴"影响"，纵轴"成本"，把事项散点放进去
- 标题写结论：`先做右上角三件，其余下季度`
- 空象限也要标出来（说明你想过）

## 8. 流程/时序页

- 横向 3–6 步，每步一个动词
- 标注**每步耗时**（这是最有信息量的部分）
- 标出卡点：`第 3 步平均等 6 天`

## 9. 时间线页（规划）

- 横向时间轴，节点 ≤5
- 每个节点带**日期 + 交付物**，不是"Q1""后续"
- 用一条横线标"今天"

## 10. 证据页（用户原话/截图）

- 一张真实截图 + 一句引用 + 一行解读
- 比任何形容词都有说服力
- 记得打码隐私信息

## 11. 风险页

- 表格：风险 / 概率 / 影响 / 应对 / 责任人
- **概率与影响都要分级**（高/中/低），不要只写"有风险"
- 至少有一条写"如果发生，最坏情况是…"

## 12. 请求页（最后一页）

- 要什么：人 / 钱 / 决策 / 时间，**写具体数量**
- 什么时候要：具体日期
- 不给会怎样：一句话说明后果
- 常见错误：最后一页写"谢谢"，等于把最关键的 30 秒浪费了

---

## 该删的页

| 页型 | 为什么该删 |
| --- | --- |
| 目录页 | 结论页替代它，且目录没有信息 |
| 「背景介绍」3 页以上 | 压缩成 1 页 SC |
| 「团队介绍」（非融资场合） | 听众不关心 |
| 纯文字的方法论页 | 你自己念就好 |
| 「谢谢」页 | 换成请求页 |
| 附录式细节 | 移到最后，讲的时候跳过 |

## 一页的四种排布（选一种，别混）

| 排布 | 适合 |
| --- | --- |
| 标题 + 一句话 + 大图 | 数据页、证据页 |
| 标题 + 三栏（每栏一个短句） | 三论点页 |
| 标题 + 表 | 对比、风险 |
| 标题 + 左侧结论栏 + 右侧图 | 分析页（最稳） |

**留白 ≥30%**。幻灯片不是文档，密度低才有人看。
